# فاحص دومينات .com القصيرة

أداة سطر أوامر (رسائلها بالإنجليزية) تبحث عن توفّر دومينات `.com` الثلاثية والرباعية — Node 18+ فقط، بدون أي مكتبة.

## كيف تفحص

1. **DNS** — يسأل خوادم سجلّ .com نفسها (`a-m.gtld-servers.net`) مباشرة: هل الدومين في ملف المنطقة؟
   الجواب فوري ودقيق، وهو ما يصفّي الأغلبية الساحقة. إن كانت شبكتك تحجب ذلك
   ينتقل تلقائياً لخادم DNS الجهاز (أبطأ، ويحيل أسماء أكثر لـ RDAP). أول سطر يطبعه يقول أيهما استُخدم.
2. **RDAP** — للباقي فقط، من سجلّ Verisign الرسمي (`rdap.verisign.com`): 404 = **متاح**، 200 = محجوز.
   ضرورية لأن دومينات محجوزة كثيرة خارج ملف المنطقة (موقوفة أو قيد الحذف) — مثل `eth.com` و`ssi.com`.

## البحث الشامل (أمر واحد)

```bash
npm run domains
```

بدون أي خيار يفحص كل شيء بالترتيب (117,309 اسم، قرابة ساعة):
1. **كلمات لها معنى** — 2,751 كلمة إنجليزية شائعة من 3-4 حروف (`words.txt`)، الأشيع أولاً
2. **الرباعي بحرف مكرر** — 98,176 اسم
3. **الثلاثي بالحروف** — 17,576 اسم

المتاح يُحفظ في `available.txt` (دومين في كل سطر)، والتفاصيل كاملة في `domains-results.csv`.
للكلمات فقط: `npm run domains -- --words`

## أمثلة

```bash
# كل الثلاثي بالحروف (17,576 اسم)
npm run domains -- --length 3

# رباعي بنمط ساكن-علة-ساكن-علة (مثل bako, tumi)
npm run domains -- --pattern CVCV

# رباعي حروف وأرقام، عيّنة عشوائية 5000
npm run domains -- --length 4 --charset alnum --shuffle --limit 5000

# أسماء من ملف (اسم في كل سطر)
npm run domains -- --file names.txt
```

## الحروف المكررة

```bash
# كل رباعي حروف فيه حرف مكرر مرتين أو أكثر (98,176 اسم)
npm run domains -- --length 4 --repeated

# بشكل تكرار محدد: الحرف نفسه في الشكل = الحرف نفسه في الاسم
npm run domains -- --shape aabb   # ccdd, mmxx  (650 اسم)
npm run domains -- --shape abab   # titi, koko  (650)
npm run domains -- --shape abba   # otto, anna  (650)
npm run domains -- --shape aaab   # zzzq        (650)
npm run domains -- --shape aaaa   # aaaa..zzzz  (26)
```

`--shape` يستخدم `--charset` (الافتراضي حروف فقط).

## رموز النمط

| الرمز | المعنى |
|---|---|
| `L` | أي حرف a-z |
| `V` | حرف علة (aeiou) |
| `C` | حرف ساكن |
| `D` | رقم 0-9 |
| `A` | حرف أو رقم |
| `X` | حرف أو رقم أو شرطة |
| `*` | حسب `--charset` |
| غير ذلك | حرفي — مثلاً `ai**` = كل ما يبدأ بـ ai |

## النتائج

المتاح فقط: `available.txt` (أو `--txt`).


تُكتب في `domains-results.csv` (أو `--out`) بالأعمدة: `domain,status,detail,checked_at`.
الحالات: `available` · `taken` · `likely-available` (مع `--no-rdap`) · `error`.

الملف يعمل نقطة استئناف: أعد تشغيل نفس الأمر ويُكمل من حيث توقف، والأخطاء تُعاد تلقائياً.
عمود `detail` للمحجوز يتضمن حالة السجلّ وتاريخ الانتهاء — `pendingDelete` أو `redemptionPeriod`
تعني أن الدومين قد يسقط قريباً.

## توقعات واقعية

- **كل** ثلاثي `.com` (حروف أو أرقام) محجوز منذ سنوات، وكذلك **كل** رباعي بالحروف فقط (LLLL).
- فرص المتاح الحقيقية: رباعي فيه شرطة (`a-bc`)، أو مزيج حروف وأرقام نادر، أو دومين سقط للتو.
- الأداة مفيدة كمراقب: شغّلها دورياً على قائمة وستلتقط ما يسقط، وراقب `pendingDelete`.

## حدود الاستخدام

RDAP لدى Verisign يحدّ من عدد الطلبات؛ الافتراضي طلبان متوازيان مع 400ms بينهما،
وعند 429 تنتظر الأداة وتعيد. لا ترفع `--rdap-concurrency` كثيراً حتى لا يُحظر عنوانك مؤقتاً.
إن ظهرت أخطاء DNS كثيرة، خفّض `--dns-concurrency` (مثلاً 15).
